# Adalm‑Pluto

Este repositorio tiene un propósito educativo: poner en marcha y documentar el uso de la placa ADALM‑PLUTO (ADALM‑PLUTO). Aquí se recopilan ejemplos, notas y recursos para que estudiantes y aficionados puedan aprender a configurar y operar el dispositivo.

## Contenido destacado

- Carpeta "Codigos Gena": ejemplos y códigos desarrollados por el autor. Estos ejemplos están pensados como material práctico y demostrativo para aprender a usar la ADALM‑PLUTO.

## Plataformas y compatibilidad

Los códigos ubicados en la carpeta "Codigos Gena" han sido probados y funcionan en:

- Windows (nativo o mediante WSL)
- Ubuntu 24

Requisitos clave:

- Librería libiio en las versiones 0.24 y 0.26. Ambos números de versión están soportados por los ejemplos incluidos.

## Recomendaciones de instalación (resumen)

- Ubuntu 24:
  - Se puede instalar libiio desde paquetes cuando estén disponibles en el sistema o compilar desde fuente si se necesita una versión específica (0.24 o 0.26).
  - Asegúrate de que las dependencias del sistema para libiio estén instaladas y que los permisos de acceso al dispositivo USB/Red estén configurados correctamente.

- Windows:
  - Si trabajas nativamente en Windows, verifica las instrucciones de instalación de libiio y la disponibilidad de controladores/soporte USB adecuados.
